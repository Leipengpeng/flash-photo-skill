# 闪光灯 Skills

Photography Relighting · 原图重打光

照片已经拍完，灯还可以重新摆。

一张自拍，脸藏在阴影里。加一盏正面直闪，脸颊和鼻尖就有了亮点。把灯搬到左边，换成大柔光箱，脸上的明暗又慢慢铺开。也可以再摆一盏灯，只照头发和肩膀。

## 两种输出

| 模式 | 你拿到的照片 |
| --- | --- |
| **模型直出** | 图像模型生成的完整打光照片，尺寸由图像模型决定。 |
| **原尺寸融合** | 把生成图里的光照映射回原片，在原片的像素网格上合成，输出宽高与原片一致的 PNG。 |

默认用模型直出。想保留相机原片尺寸，直接说「保留原尺寸」就行。想对比两种结果，可以说「两张都给我」，共用一次图像生成。

## 怎样布光

Skill 先看照片里的远近和遮挡，再分辨皮肤、衣服、玻璃和金属。接着按灯的形状、大小、方向和强度安排亮部、阴影和反光，生成完整的打光图。选择原尺寸融合时，再从成图提取照明，用原片自己的纹理合成。

可以用正面或侧面硬闪、矩形／八角／长条柔光箱、环灯、灯碟、聚光、墙顶跳闪，也可以组合主灯、补光灯和轮廓灯。

## 安装与使用

下载 [Skill 安装包](https://raw.githubusercontent.com/Leipengpeng/flash-photo-skill/main/flash-photo-skill.zip)。

- **Codex**：解压后把 `flash-photo-skill` 文件夹放进 Codex 的 `skills` 目录。Windows 默认是 `%USERPROFILE%\.codex\skills`，设置过 `CODEX_HOME` 时用它下面的 `skills` 目录。
- **豆包**：打开「技能 → 添加 → 上传技能」，选中下载的 ZIP，然后在对话中使用技能。

附上照片，再说你想要的光。

> 给这张照片加一盏明显的正面直闪，直接出图。
>
> 把灯移到左边，换成大柔光箱，输出保留原尺寸。
>
> 用主灯打亮脸，再用右后方的轮廓灯勾出头发和肩膀。模型直出和原尺寸版都给我。
