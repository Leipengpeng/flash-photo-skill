# 闪光灯 Skills

*Photography Relighting · 原图重打光*

**照片已经拍完，灯还可以重新摆。**

一张自拍，脸藏在阴影里；一张室内照片，器材和人挤在一起；一面古董镜子，反光总比人先抢镜。给一张现有照片，告诉它想要什么光：清楚利落的直闪、从侧面铺开的柔光，或只落在头发和肩上的一点暖色轮廓。

这个Skill先看照片里的远近、遮挡和材质，再安排光从哪里来、照到哪里、留下什么影子。小灯有小灯的脾气，大灯箱有大灯箱的铺陈。灯搬到左边，鼻影也得跟着换班。

成图属于**AI重打光效果**。光落在皮肤、眼镜、金属和织物上，应当各有反应。生成后还要认真看一遍，交代哪里像、哪里还差一点。

**现在可以选：直接拿到打光成图，或把光带回原片尺寸。** 两种方式都先看深度、辨材质，再生成完整的打光效果。想快速看灯，就交付 Image 成图；想保留原片的像素尺寸，就继续在本地提取照明变化，用原片自己的细节完成融合。

原尺寸融合加入了经过实拍选片的 **F06、F04**。它们不把生成图放大后盖在原片上，而是估计光照增益，再作用于原片网格。同一盏灯的参考只生成一次，换融合方法、调强度都在本地做。两版都得到过用户认可，尚未选出唯一最佳；光是否自然、边缘是否干净，仍交给看图的人决定。

原来的 V2 直接光照层和 V3 Delta 实验也继续保留，供需要比较传递方法时使用。

## 先选怎样交付

| 交付方式 | 得到什么 | 适合什么时候用 |
| --- | --- | --- |
| **直接生成** `direct` | Image 完整打光图，保留其实际输出尺寸 | 快速看光效；这是未指定时的默认方式 |
| **原尺寸融合** `native-fusion` | 同一张 Image 参考，再交付 F06 或 F04 的原片尺寸 PNG、Delta 和可重放模型 | 想保留原片的尺寸与细节来源，或在本地继续调强度 |

也可以说“两种都要”，共用一次完整打光生成。原尺寸融合默认执行 F06，可指定 F04，或两版都保留。这里的“保留原尺寸”指宽高像素数和原片底图，不表示 RGB 不变、RAW 无损或每处纹理对比都不受影响。

## 它会做什么

| 任务 | 具体做法 |
| --- | --- |
| 给原图加明显直闪 | 让近处主体明确受光，检查局部高光、面部短影和前后衰减 |
| 换一种摄影光源 | 规划圆罩、灯碟、柔光箱、环灯、面板、灯管或聚光的照明外观 |
| 调整大小与方向 | 分开设置发光面形状、表观尺寸、灯位、高度、指向和新增光强 |
| 照顾不同材质 | 分别处理皮肤、织物、毛发、玻璃、镜面和金属的受光与反射 |
| 处理镜面场景 | 分开理解实体镜面、镜中人物和灯的眩光路径，按需关闭手机闪光 |
| 安排跳闪与双灯 | 有可用墙顶才做跳闪；主灯、补光与轮廓灯分别推演遮挡和投影 |
| 选择交付方式 | 直接交付 Image 成图，或继续做 F06/F04 原尺寸融合；也可两种都要 |
| 保留原片尺寸 | 从完整参考提取变化，或直接生成光照层，再合成回原片显示网格 |
| 留下可调的光照层 | 输出透明效果层，按需保存浮点增量；保留逐灯控制图时可以独立调灯 |
| 比较不同传递方法 | 同一个完整参考复用多种本地滤波、引导与融合方法，并列交付供人工选择 |
| 检查原图有没有跑样 | 对照构图锚点、人脸、手部、器材、文字和背景，保留首稿与修订记录 |

## 想要哪盏灯

| 你想要的感觉 | 可以选的方案 | 主要看哪里 |
| --- | --- | --- |
| 正面清楚，直闪感明显 | 近轴裸灯、小圆罩硬闪 | 面部短影、集中高光、近处更强的新增光 |
| 亮部铺开，过渡柔和 | 大矩形或八角柔光箱 | 脸部亮区、鼻侧和下颌的阴影边缘 |
| 侧脸有层次，覆盖收窄 | 竖条柔光箱 | 侧脸、发缘、肩部和有条件成立的长条反光 |
| 正面补光更均匀 | 环形LED、矩形LED面板 | 正脸层次、镜片反射与可读的眼睛 |
| 头发和肩部有一点边光 | 侧后方灯管、条形轮廓灯 | 暖色外轮廓及被头发、衣物挡住的区域 |
| 光集中在一处 | 菲涅尔或束光方案 | 局部受光、束外环境与溢光边界 |
| 顶前方柔和受光 | 利用已有墙顶或遮棚跳闪 | 大面积回光和向下的柔和阴影 |
| 脸与轮廓各有照顾 | 柔光主灯＋侧后轮廓灯 | 两盏灯各自的覆盖、方向和反射 |

这些是布光设定，不是通过一张成图就能认出的器材身份证。镜片上没有八角形，也不代表八角箱没有开工；能否出现那个形状，还要看表面朝向和反射条件。

## 按哪条路线做

**直接生成：看原图 → 深度与材质辅助图 → 逐灯规划 → 完整 Image 打光图 → 审图与交付。** 这条原有路线继续可用，输出尺寸由实际图像工具决定。

**原尺寸融合：沿用上面的完整打光流程 → 原片与参考建立同画幅观测 → F06/F04 提取照明增益 → 作用于原片原尺寸网格 → 保存结果、Delta 与模型。**

F06 用多尺度区域光量估计打底，只加入结构可信、幅度受限的细光变化。F04 在结构可信处更多保留局部照明，在低置信处回退到区域估计。它们都不移动、模糊或锐化原片 RGB；深度与材质图用于上游生图规划，不作为这两个本地算法的数值输入。算法、参数与边界见 [原尺寸融合](references/native-fusion.md)。

下面两条保留为显式选择的实验路线：

**V3：看原图 → 核对辅助图并规划灯光 → 生成或复用完整打光参考 → 配准参考并求 Delta → 本地滤波/融合 → 加回原尺寸 → 交给用户选片。**

求差不等于只剩下光：完整参考里改变的脸部轮廓、衣料纹理或背景细节，也可能混进 Delta。因此要比较不同传法，记录配准、滤波、正负变化与输出范围；不能先承诺哪种最好。V3 的算法实验由用户评估美感，助手只验证尺寸、原件、数据和图层能否正确复现。

**V2：看原图 → 核对辅助图并规划灯光 → 直接生成光照层 → 处理边缘并合成回原片 → 审图与交付。**

同一原图、画幅和场景没有变化时，两条路线都能复用已经核对过的深度、材质图；换灯位后，投影与反光的来路仍要重新想。滤波参数或传递强度改变时，不必重新生图，也不必重复上传同一张照片。

普通单张加灯不强制跑完整实验目录。想比较几盏灯或几种滤波，直接说明数量和路线；算法还没选定时，记录为“待人工选择”，不替你定下来。

模型执行入口见 [SKILL.md](SKILL.md)，旧实验的数据约定见 [V3 Delta 迁移实验](references/delta-transfer.md) 和 [V2 光照层合成](references/layer-compositing.md)。

## 第一次用，照这四步

普通使用只需要提供照片、说清要求。参数表可以晚点再看，开灯之前不用先考一遍摄影器材。

1. **确认Skill可调用。** 在宿主中找到“摄影灯 · 原图重打光”，或调用 `$flash-photo-skill`。
2. **提供一张原始照片。** 可直接上传，或给宿主能够读取的本地路径。已有满意的效果参考时，说明哪张是原图、哪张只参考照明。
3. **选一种光，先做一张。** 比如“明显直闪”“左侧大柔光箱”“右后暖色轮廓”。没指定时，默认近轴明显直闪。
4. **看成图和审图结果。** 再指出具体位置：“眼镜反光挡眼睛了”“下巴阴影太弱”“围巾边缘像描了一道线”。原图和首稿会保留。

```text
使用 $flash-photo-skill。
给这张原图加明显的近轴直闪，保留原画幅、人物姿态和背景。
先出深度图、语义材质图，再生成完整直闪效果。
直接生成图和 F06 原尺寸融合图都要，保留 Delta，方便我对比。
```

## 三种常用请求

**清楚利落的直闪**

```text
使用 $flash-photo-skill。
给这张照片加明显直闪，近处主体清楚受光。
保留原环境曝光，检查眼镜反光、鼻下短影和近远衰减。
先出一张。
```

**换成侧面大柔光**

```text
使用 $flash-photo-skill。
从原图做一张左前45度的大矩形柔光箱效果。
主体受光要明确，鼻侧和下颌过渡更柔和，保留皮肤与衣料纹理。
```

**同一张照片，多摆几次灯**

```text
使用 $flash-photo-skill。
从同一原图分别做：左侧小圆罩硬闪、左侧大矩形柔光箱、右后暖色灯管轮廓。
每个方案独立出图，分别核对深度与材质、重算遮挡和反射。
保留首稿，比较照明差异，并标出仍不自然的位置。
```

镜面照片可以补一句：“关闭手机闪光，改用画面右前方的竖条灯箱；人物先在真实空间受光，再经镜面被拍到。”

## 安装

仓库目录本身就是一个Skill。宿主需要支持本地Skill、图片查看，以及能接收原图作为参考的图像生成能力。直接生成不要求运行本地融合脚本；原尺寸融合需要 Python、Pillow、NumPy、SciPy 和 OpenCV。Skill 不附带模型，也不另设出图服务。

以Codex默认目录为例；已有同名目录时先检查并保留自己的修改：

```bash
git clone https://github.com/Leipengpeng/flash-photo-skill.git ~/.codex/skills/flash-photo-skill
```

也可以下载 [Skill安装包](https://raw.githubusercontent.com/Leipengpeng/flash-photo-skill/main/flash-photo-skill.zip)，解压后把其中的 `flash-photo-skill` 文件夹放进宿主的Skill目录。确保结构是 `flash-photo-skill/SKILL.md`，别套成两层同名文件夹。若设置了 `CODEX_HOME`，使用它的 `skills` 子目录。

安装后确认宿主已经识别；没有出现时，按宿主说明刷新技能或重新打开会话。缺少图像工具时，只能准备待执行简报，不能把文字说明当成已经拍好的照片。

## 原尺寸融合怎么用

普通使用直接说：“按原来的深度、材质流程做明显直闪，同时给我 Image 成图和原尺寸融合图。”已有同源打光参考时，可以直接复用，不必再次上传、生图。

在 Skill 目录中也能单独运行本地融合：

```bash
python -m pip install -r scripts/requirements-native.txt
python scripts/native_fusion.py run --source original.jpg --reference full-flash.png --methods F06 F04 --out work/native
```

`full-flash.png` 是完整打光成图，不是蒙版。脚本只在本地计算，不调用图像服务、不下载模型、不训练。原片和参考需要相同视场角；画幅比例明显不符会拒绝处理。

输出包括 `original-sRGB.png`、工作尺度原始差值 `pair.npz`、Delta 示意图，以及每个方法的 `final.png`、原尺寸浮点 `delta_linear.npz`、`model.npz` 和参数报告。灰底 Delta 示意图仅供观察，不能当透明图层直接叠加。

想调弱刚才的光，可以复用模型：

```bash
python scripts/native_fusion.py apply --source original.jpg --model work/native/F06/model.npz --strength 0.8 --out work/weaker
```

模型绑定同一原件，调强度从原图重新合成。更多参数、F04/F06 的区别和技术验证见 [原尺寸融合](references/native-fusion.md)。

## 先做一组 Delta 实验

```text
使用 $flash-photo-skill，按 V3 做。
先生成完整的明显直闪参考，再与原图求 Delta，
尝试几种有差别的滤波、深度融合和传递方法，合成回原尺寸。
已有同源完整打光参考时优先复用，控制图片上传下载。
各方案并列保留，我来判断美感，不要替我挑最佳。
```

同一个参考可以比较普通平滑、保边、原图结构引导、深度引导、多尺度等不同处理。它们会保留或抑制不同的亮暗变化；方法列表、实际命令和文件编码见 [V3 Delta 迁移实验](references/delta-transfer.md)。

已经有完整打光参考时，也能单独运行本地实验：

```bash
python -m pip install pillow numpy scipy opencv-python
python scripts/delta_transfer.py run --source original.jpg --relit full-relit.png --methods D00 D01 D02 D05 D10 D11 --out work/delta --save-working
```

这组示例不依赖深度图，既保留直接求差对照，也比较几种传法；有同源辅助图后再加入深度、材质与软覆盖方法。`list-methods` 可以读取当前方法目录，光流分支 D13 需要显式选择。保存的 `field.npz` 可在本地继续调强度，不必重新上传或生图。

## 直接光照层怎么用（V2）

日常使用仍然只要交照片、说灯位。铺开受光的增益图用 `128` 灰色表示不变；需要集中高光或亮色轮廓时，再生成黑底的加性光层，黑色表示不加光。两类层在线性 sRGB 中合成，最后统一处理高光。编码用于控制效果，不是现场测出来的照度。

合成器也可以独立使用。下面的 `gain.png` 是已经生成并审过的光照控制图；脚本本身不负责调用图像模型。

```bash
python -m pip install pillow numpy scipy
python scripts/relight_layers.py prepare --source original.jpg --out work/reference
python scripts/relight_layers.py composite --source original.jpg --field gain.png --out work/direct-flash --save-arrays
```

单纯增益容易让皮肤只变亮、仍带着原来的肤色；暗头发也不易出现亮色轮廓。已准备好黑底高光图 `highlights.png` 时，可以单独加上这份反光：

```bash
python scripts/relight_layers.py composite --source original.jpg --field gain.png --additive-field highlights.png --additive-scale 0.2 --out work/direct-flash --save-arrays
```

这里的 `0.2` 是合成示例，需要看成图调整；高光必须落在合理的皮肤或反射表面上。小光斑不能漂进镜片、越过脸缘，轮廓也不能绕成一整圈彩线。

主要输出是原始显示尺寸的 `final.png`、透明 `effect_overlay.png` 和记录参数的 `report.json`。加上 `--save-arrays` 会保留浮点 EV 与线性颜色增量。光照场是生成式估计，中性灰也未必恰好等于 `128`；需要核对码值，并用已经检查过的 `--mask coverage.png` 保护天空或远景。

想把刚才的光调弱，不用重新生图。直接复用保存的浮点场，把新增光权重调到 `0.7`：

```bash
python scripts/relight_layers.py composite --source original.jpg --field work/direct-flash/relight_arrays.npz --field-strength 0.7 --out work/direct-flash-weaker
```

主灯、轮廓灯分别留成两张控制图后，也能分别调：

```bash
python scripts/relight_layers.py composite --source original.jpg --field main.png --field-strength 1 --additive-field rim.png --additive-strength 0.6 --additive-scale 0.2 --out work/two-lights --save-arrays
```

这份 `rim.png` 是黑底轮廓光层。将它的 `0.6` 改为 `0`，就能比较开灯前后。各灯的新增贡献在线性空间相加，最后统一处理高光；一张已经合并的双灯蒙版只能整体调节。

浮点场同时保存漫反射增益与可选的加性光，复用 NPZ 会读取两部分，不会把黑底高光丢掉。它已包含原覆盖与强度，复用时不用再做一遍旧蒙版。精确复现保留原模式、`--strength 1` 和 `--field-strength 1`；允许减光的场须保留 `--mode signed`。完整选项见 [V2 光照层合成](references/layer-compositing.md)。

透明效果层应以正常模式叠在同一张、同色彩空间的原片上。它是这张照片的效果层，换一张底图就需要重新计算；不同剪辑或修图软件的混合空间也可能影响显示。具体参数与限制见 [V2 光照层合成](references/layer-compositing.md)。

## 需要精细摆灯时

不用自己填写JSON，也可以用自然语言说明。助手会为每盏灯整理 `light_sources[]`：

| 参数 | 说人话 |
| --- | --- |
| `shape` | 主体真正看到的发光面是什么形状 |
| `effective_size` | 这个发光面在主体看来有多大、多宽，离得相对近还是远 |
| `direction`、`elevation` | 灯在哪个方向、多高 |
| `aim` | 灯头朝哪里照 |
| `emission`、`modifier` | 闪光还是常亮，使用什么整光方式 |
| `strength`、`color_intent` | 新增光要多明显，偏中性、偏暖还是偏冷 |

闪光功率可补充 `power_fraction`；灯头覆盖可补充 `beam_zoom_mm`。灯头变焦影响覆盖，不会顺手把原图的相机焦距也拧一圈。

完整约定见 [光源形状与多灯规划](references/source-shapes.md) 和 [灯光控制](references/lighting-controls.md)。

## 效果与边界

旧版已经做过真实照片上的多种布光预设展示；这些结果不自动等于每条新路线都完成了同样范围的验证。V3 每组记录完整参考、原始与处理后 Delta、配准及滤波参数，由用户比较美感。不同光源的特有外观仍可能不够明显，技术测试通过不代替人工选片。检查约定见 [审图与参数对照](references/review-and-tests.md)。

深度与材质图属于生成式推断，不是实测距离、精确法线或真实光线追踪。灯位、尺寸和强度没有现场测量时，都是创作设定。闪光与常亮在相同几何、光谱和曝光积分下，单张照片可能没有可辨差异。

V2 的照片几何与纹理来源是原片，新增光仍会改变局部颜色和细节对比。加性光能把暗像素照亮，也不会找回原图已经过曝或全黑处丢失的信息；强高光还可能压低可见纹理。低分辨率控制图仍影响细窄反光、发丝边缘与硬影定位。当前输出是 8 位 sRGB PNG，保留原尺寸不等于保留 RAW、广色域或纹理逐像素不变。光效是否自然、区别是否明显，都要看实际图片，不能只看脸有没有变亮。

用户选择直接生成时，仍可能出现肤质、小字、模糊或细小结构的重绘，以及输出尺寸降低；会单独报告这些变化。

F06/F04 以原片 RGB 为底图，可避免直接放大生成参考来替换纹理，但参考中的错位或重绘仍可能影响照明估计。强增益、显示范围裁切和低分辨率光照观察也会改变局部对比或抑制细小高光。当前交付为 8 位 sRGB PNG，保留尺寸不等于完全无损修图。

V3 的 Delta 也会带入完整参考的重绘误差。滤波与深度融合可以作为抑制方向，但不保证既去掉漂移、又完整留下每一处阴影和反光。原图网格不变，也不代表受影响像素值或细节对比不变。原始照片、完整参考和全部算法候选应同时保留。

为减少流量，优先复用本地参考和辅助图，只在需要新灯光目标时调用生成。滤波与合成在本地进行，预览页不依赖远程资源；是否自然仍由用户决定，不为追求助手评分反复上传、重生图。

本仓库和安装包包含技能说明、参考文本与合成脚本。工作照片和测试成图保存在独立工作目录，日常使用无需把照片提交到GitHub仓库。
