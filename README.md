# 摄影灯 · 原图重打光

`flash-photo-skill` 是用于已有照片重打光的 Codex Skill。它先分析场景深度和材质，再规划每盏灯的受光、遮挡、阴影与反射，实际生成图片后审查结果。

## 功能

- 模拟机顶直闪、离机硬闪、矩形/八角柔光箱、LED面板、条形箱、环灯、灯管、灯碟、聚光、跳闪和多灯。
- 分别控制发光面形状、表观大小、方向、高度、指向、闪光/常亮模式、强度与颜色意图。
- 根据前景、中景、后景及材质差异处理照明；区分玻璃、镜面、金属、湿地、织物、皮肤和毛发。
- 对照原图检查画幅、视场角、人物/动物、姿态、器材、文字及细节保留情况。

## 工作流程

1. 查看原图，记录构图锚点、允许改动和未知信息。
2. 生成并审查相对深度图、语义材质图，分开解释物理镜面与镜中虚像。
3. 逐灯规划发光面、覆盖、距离关系、遮挡、投影与镜面反射路径。
4. 从原始照片编辑成图；已认可的强闪仅作照明观感参考。
5. 实际审图，针对主要问题修订，分别报告灯光效果与内容保真程度。

同一原图与画幅未变时，可复用已审通过的深度/材质图；更换灯位或光源后仍须重新推演各灯光路。每个版本都从原始图像开始。

## 光源参数

单灯与多灯统一使用 `light_sources[]`：

| 参数 | 含义 |
|---|---|
| `shape` | 有效发光面形状，如矩形、八角、环形、条形或圆柱灯管 |
| `effective_size` | 主体看到的表观大小、宽高比、朝向与相对距离 |
| `direction`、`elevation`、`aim` | 以画面左右为准的灯位、高度与照射目标 |
| `emission`、`modifier` | 闪光/常亮模式与整光方式，分别设置 |
| `strength`、`color_intent` | 新增照明的视觉强度与颜色意图 |

需要闪光功率或灯头覆盖时可补充 `power_fraction`、`beam_zoom_mm`。名义功率不是实测曝光，灯头变焦不改变原图相机视场角。完整说明见 [光源形状与多灯规划](references/source-shapes.md)。

## 手动安装

将本目录放到 `~/.codex/skills/flash-photo-skill`，确保 `SKILL.md` 直接位于该目录下，并保留 `agents/` 和 `references/`。随后在 Codex 中调用 `$flash-photo-skill`。

需要宿主具备图片查看和图像编辑能力；本技能不附带模型、模型权重或图像服务。工具不可用时只能准备待执行简报，不能声称已生成图片。

## 使用示例

提供原始照片后，可直接输入：

```text
使用 $flash-photo-skill，给这张照片加明显的近轴直闪，保留原画幅、人物姿态和背景，先生成深度与材质辅助图，再编辑并审图。
```

```text
使用 $flash-photo-skill，从同一原图分别做左侧大矩形柔光箱和右侧小圆罩硬闪，主体亮度接近，比较阴影与金属反光，并说明还存在哪些内容漂移。
```

普通使用默认只生成一张；多方案和测试数量按请求确定。已有认可的强闪效果时可延续其主体受光强度，再更换光源形状或方向。

## 限制

- 深度与材质图是生成式推断，不是标定深度、精确法线、真实光线追踪或逐像素控制接口。
- 生成式编辑可能改变纹理、小字、模糊与面部细节，也可能降低输出分辨率；需要实际审图，不保证无损或像素不变。
- 闪光与常亮在相同几何、光谱及曝光积分条件下，单帧可能无法区分；不为制造差异而擅加拖影、光晕或色偏。
- 光源面积不等于功率。反光形状还取决于表面朝向、曲率与粗糙度，不给每块玻璃复制同一个白点。
- 跳闪需要有依据的可用墙顶；本技能不负责人物入景、换装或视频剪辑。
