# 闪光灯 Skills

*Photography Relighting · 原图重打光*

**照片已经拍完，灯还可以重新摆。**

一张自拍，脸藏在阴影里；一张室内照片，器材和人挤在一起；一面古董镜子，反光总比人先抢镜。给一张现有照片，告诉它想要什么光：清楚利落的直闪、从侧面铺开的柔光，或只落在头发和肩上的一点暖色轮廓。

这个Skill先看照片里的远近、遮挡和材质，再安排光从哪里来、照到哪里、留下什么影子。小灯有小灯的脾气，大灯箱有大灯箱的铺陈。灯搬到左边，鼻影也得跟着换班。

成图属于**AI重打光效果**。它从原始照片出发，尽量保留人物辨识度、画幅、视角和场景内容；生成后再认真看一遍，交代哪里像、哪里还差一点。光落在皮肤、眼镜、金属和织物上，应当各有反应。

## 它会做什么

| 任务 | 具体做法 |
| --- | --- |
| 给原图加明显直闪 | 让近处主体明确受光，检查局部高光、面部短影和前后衰减 |
| 换一种摄影光源 | 规划圆罩、灯碟、柔光箱、环灯、面板、灯管或聚光的照明外观 |
| 调整大小与方向 | 分开设置发光面形状、表观尺寸、灯位、高度、指向和新增光强 |
| 照顾不同材质 | 分别处理皮肤、织物、毛发、玻璃、镜面和金属的受光与反射 |
| 处理镜面场景 | 分开理解实体镜面、镜中人物和灯的眩光路径，按需关闭手机闪光 |
| 安排跳闪与双灯 | 有可用墙顶才做跳闪；主灯、补光与轮廓灯分别推演遮挡和投影 |
| 检查原图有没有跑样 | 对照构图锚点、人脸、手部、器材、文字和背景，保留首稿与修订记录 |

## 想要哪盏灯

| 你想要的感觉 | 可以选的方案 | 主要看哪里 |
| --- | --- | --- |
| 正面清楚，直闪感明显 | 近轴裸灯、小圆罩硬闪 | 面部短影、集中高光、近处更强的新增光 |
| 亮部铺开，过渡柔和 | 大矩形或八角柔光箱 | 脸部亮区、鼻侧和下颌的阴影边缘 |
| 侧脸有层次，覆盖收窄 | 竖条柔光箱 | 侧脸、发缘、肩部和有条件成立的长条反光 |
| 正面补光更均匀 | 环形LED、矩形LED面板 | 正脸层次、镜片反射与可读的眼睛 |
| 头发和肩部有一点边光 | 侧后方灯管、条形轮廓灯 | 暖色外轮廓及被头发、衣物挡住的区域 |
| 光集中在一处 | 菲涅尔或束光方案 | 局部受光、束外环境与溢光边界 |
| 顶前方柔和受光 | 利用已有墙顶或遮棚跳闪 | 大面积回光和向下的柔和阴影 |
| 脸与轮廓各有照顾 | 柔光主灯＋侧后轮廓灯 | 两盏灯各自的覆盖、方向和反射 |

这些是布光设定，不是通过一张成图就能认出的器材身份证。镜片上没有八角形，也不代表八角箱没有开工；能否出现那个形状，还要看表面朝向和反射条件。

## 固定下来的工作流程

**看原图 → 生成并核对深度与材质辅助图 → 逐灯规划受光、阴影和反射 → 从原图生成 → 实际审图 → 必要时一次重点修订 → 交付。**

同一原图、画幅和场景没有变化时，可以复用已经核对过的辅助图；换灯位后，投影与高光的来路仍要重新想。已有满意的强闪版本，可以沿用它的受光观感；下一张仍从原始照片开始。

默认近轴明显直闪，只出一张。想比较几种灯，直接说明数量和方案；也可以说“保持这张的强度，把灯换到右边”。

模型执行入口见 [SKILL.md](SKILL.md)，辅助图的具体约定见 [深度与材质](references/maps-and-prompts.md)。

## 第一次用，照这四步

普通使用只需要提供照片、说清要求。参数表可以晚点再看，开灯之前不用先考一遍摄影器材。

1. **确认Skill可调用。** 在宿主中找到“摄影灯 · 原图重打光”，或调用 `$flash-photo-skill`。
2. **提供一张原始照片。** 可直接上传，或给宿主能够读取的本地路径。已有满意的效果参考时，说明哪张是原图、哪张只参考照明。
3. **选一种光，先做一张。** 比如“明显直闪”“左侧大柔光箱”“右后暖色轮廓”。没指定时，默认近轴明显直闪。
4. **看成图和审图结果。** 再指出具体位置：“眼镜反光挡眼睛了”“下巴阴影太弱”“围巾边缘像描了一道线”。原图和首稿会保留。

```text
使用 $flash-photo-skill。
给这张原图加明显的近轴直闪，保留原画幅、人物姿态和背景。
先生成深度与材质辅助图，再编辑并实际审图。
交付一张，并说明闪光是否到位、哪些细节有漂移。
```

## 三种常用请求

**清楚利落的直闪**

```text
使用 $flash-photo-skill。
给这张照片加明显直闪，近处主体清楚受光。
保留原环境曝光，检查眼镜反光、鼻下短影和近远衰减。
先出一张。
```

**换成侧面大柔光**

```text
使用 $flash-photo-skill。
从原图做一张左前45度的大矩形柔光箱效果。
主体受光要明确，鼻侧和下颌过渡更柔和，保留皮肤与衣料纹理。
```

**同一张照片，多摆几次灯**

```text
使用 $flash-photo-skill。
从同一原图分别做：左侧小圆罩硬闪、左侧大矩形柔光箱、右后暖色灯管轮廓。
每个方案独立出图，分别核对深度与材质、重算遮挡和反射。
保留首稿，比较照明差异，并标出仍不自然的位置。
```

镜面照片可以补一句：“关闭手机闪光，改用画面右前方的竖条灯箱；人物先在真实空间受光，再经镜面被拍到。”

## 安装

仓库目录本身就是一个Skill。宿主需要支持本地Skill、图片查看，以及能接收原图作为参考的图像生成/编辑能力。Skill提供工作规则，出图由宿主实际可用的图像工具完成。

以Codex默认目录为例；已有同名目录时先检查并保留自己的修改：

```bash
git clone https://github.com/Leipengpeng/flash-photo-skill.git ~/.codex/skills/flash-photo-skill
```

也可以下载 [Skill安装包](https://raw.githubusercontent.com/Leipengpeng/flash-photo-skill/main/flash-photo-skill.zip)，解压后把其中的 `flash-photo-skill` 文件夹放进宿主的Skill目录。确保结构是 `flash-photo-skill/SKILL.md`，别套成两层同名文件夹。若设置了 `CODEX_HOME`，使用它的 `skills` 子目录。

安装后确认宿主已经识别；没有出现时，按宿主说明刷新技能或重新打开会话。缺少图像工具时，只能准备待执行简报，不能把文字说明当成已经拍好的照片。

## 需要精细摆灯时

不用自己填写JSON，也可以用自然语言说明。助手会为每盏灯整理 `light_sources[]`：

| 参数 | 说人话 |
| --- | --- |
| `shape` | 主体真正看到的发光面是什么形状 |
| `effective_size` | 这个发光面在主体看来有多大、多宽，离得相对近还是远 |
| `direction`、`elevation` | 灯在哪个方向、多高 |
| `aim` | 灯头朝哪里照 |
| `emission`、`modifier` | 闪光还是常亮，使用什么整光方式 |
| `strength`、`color_intent` | 新增光要多明显，偏中性、偏暖还是偏冷 |

闪光功率可补充 `power_fraction`；灯头覆盖可补充 `beam_zoom_mm`。灯头变焦影响覆盖，不会顺手把原图的相机焦距也拧一圈。

完整约定见 [光源形状与多灯规划](references/source-shapes.md) 和 [灯光控制](references/lighting-controls.md)。

## 效果与边界

当前方法已经做过真实照片上的多种布光预设展示。它会检查来光方向、阴影软硬、材质反射和场景内容，但不同光源的特有外观仍可能不够明显。美人碟、面板和条形箱需要逐图判断；灯管轮廓可能出现连续描边，聚光也可能溢到预定范围之外。审图约定见 [审图与参数对照](references/review-and-tests.md)。

深度与材质图属于生成式推断，不是实测距离、精确法线或真实光线追踪。灯位、尺寸和强度没有现场测量时，都是创作设定。闪光与常亮在相同几何、光谱和曝光积分下，单张照片可能没有可辨差异。

生成式编辑还可能改变肤质、小字、模糊和细小机构，或降低输出分辨率。主要结构保留与细节无损是两件事；会分别报告照明效果和内容保留程度。柔光是否自然，要看受光过渡，不能只看脸有没有被磨平。

本仓库和安装包只含技能说明与参考文本。工作照片和测试成图保存在工作目录，日常使用无需把照片提交到GitHub仓库。
