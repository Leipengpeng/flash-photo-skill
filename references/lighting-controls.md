# 闪光灯与柔光控制

用于把深度、材质和灯位分析转成最终图片编辑指令。以下数值是虚拟摄影控制，不是实测曝光或某一设备的校准结果。

## 单灯字段与兼容起点

本页保留早期闪光控制字段；新方案以 [光源形状与多灯规划](source-shapes.md) 的 `light_sources[]` 为准。`emission_mode` 映射 `emission`，`flash_strength` 映射 `strength`；旧预设 `F1-near-axis/F2-left-hard/S1-left-soft/B1-ceiling-bounce` 分别映射 `P1-axis-hard/P2-left-hard/A1-rectangle/B1-ceiling`，实际形状与方向仍需检查。明确强闪或已认可强闪的用户目标优先于下表兼容起点。

| 字段 | 可选值 / 默认值 | 含义 |
|---|---|---|
| `emission_mode` | `flash` / `continuous` | 瞬时闪光或持续发光，按每源独立设置 |
| `modifier` | `bare` / `softbox` / `bounce`等 | 小光源直打、柔光箱、借墙顶反射 |
| `preset` | `F1-near-axis`等旧别名 | 灯位与光质组合，见下表 |
| `power_fraction` | `1/32`等可选相对起点 | 同一虚拟闪光灯的相对输出；不代替视觉强度目标 |
| `beam_zoom_mm` | `35`（默认起点）等 | 灯头覆盖角标记，非相机镜头焦距 |
| `flash_strength` | `low` / `medium` / `high` | 画面中新增照明的视觉强度；新默认和已选强闪见主技能 |

用户已指定的参数优先。未给距离时记录前景 / 主体 / 远景的相对关系，不编造米数。
用户口语中的“K1”只作待解释的别名，不据此认定产品型号、实际功率或灯头结构。
“柔光”默认映射到 `emission_mode=flash, modifier=softbox`；只有用户要求常亮时才用 `continuous`。

## 功率档与视觉强度

`power_fraction` 表示相对闪光输出，常以“功率档”称呼；它不等于峰值电功率，也不等于画面亮度百分比。
同一设备、距离、变焦、附件与相机曝光条件不变时，输出减半约减少一档闪光曝光。

| `power_fraction` | 相对满输出 | 相对满输出的档数 |
|---|---:|---:|
| `1/1` | 100% | 0 EV |
| `1/2` | 50% | −1 EV |
| `1/4` | 25% | −2 EV |
| `1/8` | 12.5% | −3 EV |
| `1/16` | 6.25% | −4 EV |
| `1/32` | 3.125% | −5 EV |
| `1/64` | 1.5625% | −6 EV |
| `1/128` | 0.78125% | −7 EV |

真实闪光灯的可用范围取决于型号；这些是便于沟通的常见整档，并非设备支持列表。
没有 GN、ISO、光圈、灯到主体距离和附件损失时，不能从 `1/32` 推导主体应增加多少 EV。
生成式编辑时让 `flash_strength` 描述目标观感，把 `power_fraction` 保留为本次虚拟灯组内的相对控制。
三档比较尽量固定其他参数；不可为每个档位分别自动补偿曝光，抵消用户要看的强弱差异。

| `flash_strength` | 默认视觉目标 | 相对功率起点示例 |
|---|---|---|
| `low` | 轻微填补主体暗部，原有环境光仍主导 | `1/64` |
| `medium` | 明确的主体补光，保留肤色和高光纹理 | `1/32` |
| `high` | 鲜明的直闪观感，允许小面积高光接近白 | `1/16` |

上表只是同一场景的比较起点，不能跨图宣称相同曝光。高强度也不允许整片皮肤、衣服或玻璃失去信息。

### 明显直闪与“效果不明显”的反馈

用户要鲜明直闪或认为上一版太弱时，把视觉目标改成明确的强闪，保留首稿并从原图重新编辑。可将同一虚拟设备名义输出提高至1/8或1/4作为创作起点；没有标定就不能据此宣称实际增加了多少曝光。不要因保护细节而把整个效果退回几乎不可辨的填光。

至少观察近处皮肤/衣料/物件受光是否明显增强、材质高光是否局部化、同源鼻下/镜框/接触短影是否更清楚，以及前后距离响应。小面积高光可接近白，主要皮肤、白毛和浅色衣物仍应可读；增加锐度、磨皮或全局抬曝光不能替代直闪。原环境曝光与背景信息仍需单独检查，不能偷偷换蓝天、压暗整幅背景来冒充强度。

镜面自拍需明确本版光源：离机补光不一定有可见闪光点；模拟已有手机后闪时，可以在镜中对应手机LED附近出现紧凑亮斑及少量局部光晕。亮斑不可随机置于镜子中央、遮掉整张脸或伴随新增设备；实际位置要依据原手机与镜面关系，胸前手机不能无说明地兼作高位棚灯。强闪版与离机弱补光同时改变了光源方案，不称为只改变功率的严格对照。
持续灯模式下令 `power_fraction=null`；以 `flash_strength` 表达本次照明强弱，不伪装成已知流明或瓦数。
官方依据：[Canon EL-1 手动闪光](https://cam.start.canon/en/A003/manual/html/UG-02_Advanced_Flash_0090.html)。

## 灯头变焦与原图视场角

`beam_zoom_mm` 使用全画幅等效覆盖角的习惯标记；它只控制闪光照到多宽的区域。
改变它不能缩放、裁切、重构透视、改变景深或模拟换相机镜头。

| `beam_zoom_mm` | 光束倾向 | 适合的照明意图 |
|---|---|---|
| `24` | 宽覆盖 | 近距离多人、较宽前景 |
| `35` | 较宽 | 默认直闪，主体兼顾少量环境 |
| `50` | 中等 | 主体集中，减少侧边溢光 |
| `85` | 较窄 | 局部强调，背景边缘少受光 |
| `105` | 窄 | 更集中地照主体或指定物体 |
| `200` | 很窄 | 仅用于明确需要的束光效果 |

这些不是严格光束角或照度表。附件、灯头结构与真实设备会改变分布。
聚光不意味着硬度必然增加；阴影软硬主要由主体看到的有效光源角尺寸决定。
使用 `softbox` 时，记录灯头设置，但最终覆盖和高光形状以柔光箱发光面为准。
使用 `bounce` 时，以墙顶反射区作为有效光源；不能把灯头标记当作最终出光角。
原图镜头焦距未知时保持 `camera_focal_length=unknown`，不把 `beam_zoom_mm` 填进去。
官方依据：[Canon EL-1 闪光覆盖设置](https://cam.start.canon/en/A003/manual/html/UG-02_Advanced_Flash_0080.html)。

## 两个独立轴：发光时间与光源形状

闪光 / 常亮描述时间；硬光 / 柔光描述空间光质。两者不能互相替代。

| 组合 | 阴影与反射处理 |
|---|---|
| `flash + bare` | 小而清晰的高光、较硬投影，适合近轴直闪 |
| `flash + softbox` | 较宽的明暗过渡，玻璃上可能出现柔光箱形状反射 |
| `continuous + bare` | 仍可形成硬光；单帧不自动增加运动模糊 |
| `continuous + softbox` | 柔和照明；单帧不必能与同几何的柔光闪图区分 |
| `flash + bounce` | 用反射区大小和位置决定软硬、方向及偏色 |

大光源靠近主体通常更柔；同一柔光箱远离后角尺寸变小，可变得更硬。
小型乳白罩若没有显著扩大有效发光面或借助墙顶，不保证产生大柔光箱效果。
默认保留原图运动状态；不能因为新增闪光就恢复本来模糊的手、头发或背景细节。
依据：[broncolor 光质说明](https://broncolor.swiss/news/hard-soft-and-diffused-light-what-is-the-difference)、[Profoto 柔光箱与闪光/持续灯兼容](https://support.profoto.com/support/solutions/articles/79000139707-which-lights-are-the-profoto-softbox-compatible-with-)。

## 方位、灯头指向与背景

左右一律以成片画面为准，避免“摄影师左 / 人物左”混用。
水平角 `azimuth_deg=0` 表示靠近相机光轴；负数为画面左侧灯位，正数为画面右侧。
`elevation_deg=0` 表示与主体受光区近似同高；正数表示灯在上方。
这些角度是灯在主体周围的位置描述，不是从单图测得的三维标定。
`aim_target` 单独说明灯头朝主体、白墙或天花板；跳闪的灯位与有效来光方向可能不同。

| 预设 / 情况 | 建议起点 | 主体与后景影响 |
|---|---|---|
| `F1-near-axis` | `flash, bare`；水平 0°；略高于镜头 | 正面明确补光；影子多藏在主体后方，邻近墙面仍可能出现偏下的小偏移投影 |
| `F2-left-hard` | `flash, bare`；水平 −45°；高位约 20–30° | 主体画面左侧受光，阴影偏右及偏下；后墙可见侧向硬投影，受遮挡区不应同样提亮 |
| 右 45°硬光 | `flash, bare`；水平 +45°；高位约 20–30° | 上一行的左右镜像；仅镜像照明关系，不能翻转原图 |
| `S1-left-soft` | `flash, softbox`；水平 −45°；略高于眼睛 | 较宽过渡与更大的柔和高光；后景投影变软，仍保留方向与接触阴影 |
| 高位直打 | `flash, bare`；水平接近 0°；明显高位 | 头顶、鼻梁、肩部先受光；鼻下、下颌和物体背向面形成阴影，不能抹平为均匀提亮 |
| `B1-ceiling-bounce` | `flash, bounce`；指向已存在的浅色天花板 | 有效来光偏上，环境溢光更多；眼窝/下颌可能较暗，不能假设所有阴影消失 |

角度是可调摄影意图，不要求从二维图伪造精确坐标。投影最终落向由墙、地与主体几何共同决定。
贴墙主体的投影更容易显现；主体离墙后的影子尺寸和软硬还受灯到主体距离、光源尺寸影响，不能只靠“离墙更远”判断。
近主体的灯往往造成前后受光差异更强；较远灯在相同主体曝光下可让不同深度受光更均匀。
真实场景没有可用墙顶时，不凭空加入跳闪表面；改用已存在的反射面或其他预设。
有色墙顶可能给反射光染色；不是把整张图统一改白平衡。
依据：[Canon 跳闪](https://cam.start.canon/en/A003/manual/html/UG-02_Advanced_Flash_0070.html)、[Nikon 闪光基础](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/the-basics-of-flash-photography)。

## 深度衰减与曝光边界

用相对深度和遮挡关系决定前景、中景、后景受到多少新增光，距离必须从灯而非相机起算。
只有近轴灯时，相机深度顺序才常能近似灯距顺序；侧灯、后灯必须重新判断。
点光源近似下，单次闪光造成的曝光贡献可定性写作：

```text
H_flash ∝ power_fraction × beam_weight × max(0, cos(theta)) × visibility / r²
```

`r` 是灯到表面的距离；`theta` 是入射方向与表面法线夹角；`visibility` 表示遮挡；`beam_weight` 表示光束内的位置。
这只是相对趋势模型，不是从 JPEG 像素直接求照度的算法，也不是已运行的光线追踪。
大柔光箱近场、墙顶跳闪、多次反射、强定向光学系统不能机械套用单点 `1/r²`。
点光源近似且其他条件相同时，距离翻倍意味着直接照明约为四分之一；不是所有像素亮度都除以四。
不从生成的深度灰度值推导绝对距离；天空、玻璃、镜中内容尤其不能当作普通实体深度。
若实际写像素合成算法，需处理线性光与显示编码；不能在 sRGB 上简单叠一张白色蒙版冒充物理照明。
原环境光保持存在，闪光只增加其能照到的区域；默认不把远景整体压暗。
主体变亮后远景可以在视觉对比中显得更暗。若用户明确要求压环境，再记录单独的环境曝光调整。
依据：[PBRT 点光源](https://www.pbr-book.org/4ed/Light_Sources/Point_Lights)、[ERCO 距离定律](https://www.erco.com/en_us/knowledge/fundamentals/photometric-law-of-distance/)。

## 材质、反射与透明物体

材质分割回答“哪里是什么”，法线与灯位推断回答“哪里可能反到镜头”，两者不能互相替代。
同一地面内也可有哑光砖、湿斑、镜面石材，不能按“地面”统一做高光。

| 材质 | 新增照明应体现 | 应避免 |
|---|---|---|
| 普通哑光地面 / 墙 | 方向性漫反射、遮挡与接触阴影 | 整片镜面化 |
| 平面玻璃 / 窗户 | 几何允许处出现局部灯源反射，同时保留透过玻璃的场景 | 整块刷白、透明度归零 |
| 玻璃杯 / 弯曲玻璃 | 局部亮点或条状反射，形状随曲率变化，保留杯沿 | 每个杯子贴同一白点 |
| 镜子 / 抛光金属 | 符合视线与法线关系的反射；可见反射内容保持位置 | 无条件制造相机、人物或新增镜中灯具 |
| 湿地 / 水面 | 有方向性的延展或碎裂高光，受微表面与视角影响 | 所有湿地同时变成均匀白色反光板 |
| 皮肤 / 皮革 / 漆面 | 小光源较集中、大光源较宽的高光，并保留表面纹理 | 纯白塑料皮肤、自动磨皮 |
| 逆反射材料 | 若有可靠材质线索，近轴闪光可能显著回亮 | 把普通白衣当逆反射布 |

理想镜面满足相对表面法线的入射角等于反射角。只有反射路径进入镜头时才呈现明显灯源高光。
粗糙表面把反射扩展到一片方向；透明介质的反射与透射还受角度和折射率影响。
近轴闪光照到正对相机的玻璃时较容易形成眩光，但“有玻璃”不等于“一定整片反光”。
保留原来合理的反射、透视和折射结构，只添加新灯带来的变化；不以反射图替换原图。
未知法线或材质时，采用保守局部高光并标记低置信度，避免强制生成精确光斑。
依据：[PBRT 镜面反射与透射](https://www.pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission)。

## 交给最终图像编辑器的约束

把原图设为唯一构图与身份依据；深度图、材质图及光路图只用于解释照明。
明确写出灯位、有效光源尺寸、受光范围、前中后景变化、预期影子、反射位置与不确定处。
保留相机视场角、边界裁切、人物身份、姿态、物体数量、文字、纹理、建筑线和原有景深。
不得把辅助图的灰度、类别色、箭头、文字、框线或网格带入成片。
验收时逐项比对原图；构图漂移或材质被改写时先修复保真问题，再微调强度。
