# V3：完整打光参考的 Delta 滤波迁移

用户要求“先生成完整结果，再相减、滤波、加回原片”时采用本路线。它与 [V2 直接光照层](layer-compositing.md) 并列：这里的模型先画完整打光参考，算法再提取和传递变化；不能把它描述成模型直接输出蒙版。

本轮是算法候选实验。技术检查由助手完成，所有方案的美感、自然度与取舍由用户决定。保持候选平等，不按主观评分排序，不替用户选最佳，也不隐藏审美上不喜欢的版本。

## 数据角色与公式

| 数据 | 角色 |
| --- | --- |
| 原始照片 `O` | 最终像素网格、人物、文字与原片细节的来源；原文件不覆盖 |
| 完整打光参考 `R` | 按 V1 风格生成或从同一原图的历史结果复用；提供本次待迁移的变化 |
| 原图工作副本 `O_l` | 对 EXIF 转正、ICC 色管后的原图作全画幅缩小，以对应参考尺寸 |
| 已配准参考 `R_a` | 把参考对应到 `O_l`；只变换参考，不能扭曲原片 |
| 原始 Delta | `D = R_a − O_l`，有正有负的线性 RGB 变化场 |
| 滤波后 Delta | `D_f = F(D; O_l, depth, materials, …)`，各方法分别保留 |
| 最终照片 | 将 `D_f` 传回原始网格，计算 `O_h + strength × D_h`，再处理显示范围与编码 |

在统一的线性 sRGB 中求差和相加，不直接用不同 ICC、EXIF 方向或尺寸的 JPEG/PNG 码值相减。默认保留正负变化：正值可以增加亮度或某颜色通道，负值可以表达参考中的阴影、压暗或调色。用户已选择此有符号迁移实验时，不再套用 V2 的逐通道 `add-only` 截断。覆盖保护、负增量抑制或远景门控若参与比较，应单列方法与参数，不悄悄施加到所有对照。

完整参考中的颜色、几何和纹理漂移都会进入 `R−O`。求差不是从单张照片分离出“真实照明”的证明；配准、置信加权和滤波也可能连同真正的新阴影或细小反光一起削弱。这里比较的是传递策略，不预先断言 Delta 更准确或某种滤波更自然。

## 先取得一次完整参考

沿用原有深度—材质—逐灯规划，使用 [整图编辑模板](maps-and-prompts.md#v1-整图编辑模板) 生成完整打光参考。原图始终是内容、身份、FOV 和几何权威；深度与材质图只作已审查的定性辅助。保持完整画幅，不先裁原图去迁就模型尺寸。

同一原件已有完整生成的强闪、侧柔或双灯结果时，可以直接复用，并记录源文件哈希、原始提示词、实际尺寸和来源。不要把 V2 直接蒙版合成的照片混称为本轮完整生成参考。参考即使包含可见重绘，也可作为待比较输入保留；不先按助手的美学偏好筛选后冒充全部结果。

需要新参考时，每个光照目标先生成一张适当尺寸的全画幅参考。后面的不同滤波和强度都复用它，在本地运算，不为每个算法重新上传原图或调用生图。无需为只改变滤波参数重做深度、材质或完整参考。

## 配准与辅助图

先核查原件显示方向、参考画幅和三个跨区域锚点，再进行可记录的参考配准。留存未配准参考、配准变换、位移界限、失败/回退状态。小全局配准不等于修复了生成的人脸、手部和文字；局部光流也可能把阴影边界当作物体移动，不能宣称其必然正确。原图网格不裁切、不几何变换，最终图片也不由配准后的参考直接放大替代。

深度图是相对推断，不是米制距离或表面法线。可用作滤波引导或近远区域权重，不能把灰度值直接当真实灯距套入平方反比。材质类别图也不是精确 alpha：要记录其分辨率、重采样方式和分类边界限制。纯算法与辅助图融合方案都保留，便于用户比较是否值得增加约束。

## 候选方法与比较条件

对同一完整参考，优先固定工作尺度、色管、配准基准和合成强度，再比较算法。未滤波求差保留为对照。若一项同时改变配准、空间滤波、深度门控或强度，要在方法说明中逐项写清楚，不能把全部差异归因于单个滤波器。

当前实现提供以下方法，编号仅为稳定标识，不是排名。尺度均以实际工作图为单位，不能当作毫米、灯距或实测功率。

| ID | 处理 | 本实现主要条件 |
| --- | --- | --- |
| D00 | 未配准原始差值 | 保留参考未配准状态，直接求差；配准对照 |
| D01 | 配准后原始差值 | 使用本次配准结果，Delta 不另滤波 |
| D02 | 小尺度高斯 | Delta 空间平滑，`sigma=2` |
| D03 | 大尺度高斯 | Delta 空间平滑，`sigma=8` |
| D04 | 差值自身双边 | 以 Delta 自身差异保边；邻域 `9`，颜色尺度 `0.08`，空间尺度 `5` |
| D05 | 原图亮度引导 | 原图结构作引导，半径 `12`、正则项 `0.002` |
| D06 | 深度引导 | 相对深度图作引导，半径 `20`、正则项 `0.003` |
| D07 | RGB 与深度联合双边 | 稀疏联合邻域；半径 `4`、步长 `2`，结合原图颜色与相对深度 |
| D08 | 材质分区归一卷积 | 固定八类材质近邻分类，各类内 `sigma=6` 的归一平滑；不自动证明分类准确 |
| D09 | 低中频与结构置信 | 粗尺度 `12` 与细尺度 `2` 分解，中频权重 `0.65` 乘结构差异启发式置信 |
| D10 | 对数亮度增益加色差 | 分离亮度比与剩余色差；增益平滑 `5`、色差平滑 `8`，对数增益限幅 `±6` |
| D11 | 屏蔽泊松平滑 | 解 `(I + 20L)u = Delta`，Neumann 边界的 DCT 求解；不是无缝克隆或真实光照重建 |
| D12 | 深度加软覆盖融合 | 深度引导后乘软覆盖与近远权重；覆盖平滑 `12`、深度权重底值 `0.25`，只在此方法对 Delta 门控 |
| D13 | 受限光流加引导传达 | 可选实验：全局配准后再作受限双向光流采样，工作尺度位移上限 `12`、往返阈值 `1.5`，随后原图引导 |

D10 是不同的传递表示：原尺寸中按 `O × 2^(strength × log_gain) + strength × chroma_delta` 合成，并非简单把同一 RGB Delta 线性缩放。其暗部稳定项与增益限幅也可能改变参考外观，须与其他方法分别标注。D13 同时改变局部配准和滤波，不能将它与 D01 的所有差别归因于某个滤波器。光流不可信处保留全局参考；一致性阈值不证明真实表面对应。

脚本默认目录为 D00–D12；D13 标为可选，不自动开启。用 `list-methods` 读取实际目录与参数，输出报告记录本次使用值。默认方法需要的深度、材质和覆盖图缺失时应选择可运行子集，不能伪造辅助图或悄悄改用别法。

普通单图任务不强制遍历整个目录。用户要求多方案实验时按约定数量交付；用户选定方法后，后续可复用其标识与参数。没有用户反馈就记录“待人工选择”，不自行写为已认可默认算法。

## 本地运行与复用

`scripts/delta_transfer.py` 依赖 Python、Pillow、NumPy、SciPy 和 OpenCV，并复用同目录的色彩处理/透明层工具；不调用生图服务。`--relit` 必须是已经取得的完整打光参考。

```bash
python -m pip install pillow numpy scipy opencv-python
python scripts/delta_transfer.py list-methods
python scripts/delta_transfer.py run --source original.jpg --relit full-relit.png --registration ecc --methods D00 D01 D02 D05 D10 D11 --out work/delta --save-working
```

已有同源深度、材质和覆盖图时，可显式比较全部方法，包括可选光流分支：

```bash
python scripts/delta_transfer.py run --source original.jpg --relit full-relit.png --depth depth.png --materials materials.png --coverage coverage.png --registration ecc --methods D00 D01 D02 D03 D04 D05 D06 D07 D08 D09 D10 D11 D12 D13 --strength 1 --max-edge 1600 --out work/delta-all --save-working
```

一次 `run` 为同一参考共享解码、工作尺度与全局配准；D00 保留未配准对照，D13 再作其专用局部分支。`--registration identity` 可以关闭全局配准。ECC 使用有界平移/旋转；不收敛或超出界限时回退原参考并写记录。若提供覆盖图，它可用于全局配准的背景定位，但除 D12 外不因此硬切其他方法的 Delta。

`--max-edge` 默认 `1600`，只控制工作图，不把较小参考向上放大，也不降低最终原片尺寸。`--strength` 支持 `0..3`、默认为 `1`；零为恒等核查。参考/辅助图宽高比与原片显示画幅偏差超过 `1%` 时拒绝处理，小于容差也不能宣称精确配准。

保存工作场后，调强度无需新生图或重复滤波：

```bash
python scripts/delta_transfer.py apply --source original.jpg --field work/delta/D05/field.npz --strength 0.8 --out work/delta-weaker
```

缓存绑定原文件哈希；不要把不同原图或重新编码后的副本传入并声称精确复现。增减强度与方法切换也由用户决定，示例数值不是推荐审美设置。

`run` 的目录包括：

- `original-sRGB.png`：转正、统一色管的原尺寸底图，供透明层复现。
- `_working/`：原图工作副本、未配准与配准后参考、结构置信及已有辅助图的工作副本、`pair.json`。
- 每个 `Dxx/`：原尺寸 `final.png`、`effect_overlay.png`、浏览用 `preview.jpg`、三种 Delta 预览和 `report.json`。
- 选择 `--save-working` 时，每个 `Dxx/field.npz`：工作尺度 float32 `delta_linear`，或 D10 的 `log_gain` 与 `chroma_delta`，并含源/参考哈希和方法标识。
- `manifest.json`：实际方法目录、参数与路径；不含美学排名。

`apply` 从同一原件与缓存重算原尺寸成品和透明层，写入新目录，不覆盖原件。它不自动再运行配准、滤波或 V2 的亮部趋白。

## Delta、预览与透明层

有符号浮点 Delta 与普通灰度 alpha 蒙版不同，应保留原始、处理后工作尺度的数据及方法参数，便于本地再次调整强度。正/负变化分图或有中性零点的伪彩预览只用于看变化位置，必须注明零点、符号与显示尺度，不能把这类显示图直接加回照片。

本实现的 `delta-signed.png` 按每通道 `128 + 127 × Delta / 0.25` 编码，`128` 为零；`delta-positive.png` 与 `delta-negative.png` 分别显示正值和负值幅度，`0.25` 的线性变化映射至最大亮度。超出显示范围会被截断，预览不能代替保存正负号的浮点场。

最终 `effect_overlay.png` 是针对当前同一 sRGB 底图求出的正常透明度效果层，用于在普通软件复现已合成结果。它既不是原始线性 Delta，也不是可换底的通用照明素材；目标软件使用其他混合空间时，应核对差异。

合成保留原片显示尺寸，但受影响 RGB 值、局部对比和输出量化都会变化。当前结果不称为 RAW、广色域或原像素值无损；滤波后的残差仍可能带入生成纹理或错位轮廓。不要用 V2 的手画高光或自动趋白处理暗中修改 Delta 实验，否则需另列为处理条件。

## 技术检查与人工选片

助手只检查可验证的流程事实，并与人工美学评估分开记录：

- 原文件哈希不变，输出尺寸等于 EXIF 转正后的原始显示尺寸。
- 输入参考、深度/材质来源、色管、工作尺度和配准变换有记录。
- 零 Delta 或零强度能还原同色管底图；求差保留正负号，数值为有限值。
- 原尺寸结果、透明层重建误差、裁切/溢出统计与实际输出路径可核验。
- 各方案按统一展示比例并列，提供原图、完整参考与结果对比；显示参数可查看。
- 技术失败也保留方法标识、参数与错误，不伪造图片或静默改用其他算法。

这些通过不等于光照自然、灯型可辨或比旧版更好。用户可以记录喜好、问题位置和待调参数；助手依用户反馈继续做局部实验，不替其完成审美选择。

## 流量与本地缓存

优先使用已有完整参考、原始照片和同源辅助图。各方法共享一次解码、缩放和配准缓存，后续滤波、Delta 放大与原尺寸合成都在本地完成。预览页不引入远程脚本、字体或图片；缩图用于浏览，原尺寸文件按需打开。

报告区分“新增生图/图片上传下载的实际调用”与整个聊天的网络传输。复用全部本地素材时可以写“本轮未新增图片上传、下载或生图调用”，不能据此声称整个聊天没有网络流量，也不要编造未测量的带宽字节数。私人照片、完整参考和实验成品留在工作目录，不进入技能安装包。
