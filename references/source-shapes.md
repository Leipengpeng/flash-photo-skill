# 光源与灯位

以成片的左右为准。每盏灯分别设定发光面形状、表观大小、方位、高度、指向、覆盖、强度和颜色。灯的表观大小影响阴影软硬，束光附件或灯头变焦影响覆盖。闪光和常亮都按单帧里的受光来设计。

| 布光 | 起点 | 画面效果 |
| --- | --- | --- |
| 正面直闪 | 镜头附近的小发光面，强光 | 正面受光、集中高光、下巴或鼻侧短影，近处比远处更亮 |
| 左前硬光 | 左前方约 45° 的小发光面 | 受光集中在左侧，短影向右延伸 |
| 矩形柔光箱或面板 | 左前上方的大矩形发光面 | 受光区较宽，皮肤过渡柔和，亮面反射呈矩形倾向 |
| 八角柔光箱 | 右前上方的大八角发光面 | 柔和塑形，光滑表面可见近圆的高光 |
| 环形补光 | 镜头周围的环形发光面 | 正面填光较均匀，眼部或镜片可见环形反光 |
| 长条柔光箱或灯管 | 侧方的竖向长窄发光面 | 侧脸、发缘或器材出现细长受光带 |
| 高位灯碟 | 主体前上方的中等圆形发光面 | 鼻下和下颌有清楚的阴影，过渡比小灯宽 |
| 聚光 | 小光源加束光罩，瞄准主体局部 | 光集中在指定区域，束外保持环境光 |
| 顶面跳闪 | 用现场浅色顶面反射 | 从上方铺开的柔光 |
| 侧墙跳闪 | 用现场浅色侧墙反射 | 靠墙一侧更亮，反射光带墙面色调 |
| 主灯加补光 | 左前大面主灯，右前弱辅灯 | 保留主方向，同时抬起背光一侧 |
| 主灯加轮廓灯 | 前方主灯，侧后方条形灯 | 主灯打亮脸，侧后灯勾出朝向它的头发和肩膀 |

每盏灯分别规划新增受光、遮挡物和接影面。大柔光箱让明暗过渡变宽，并保留来光方向。玻璃保留透射，镜面保留原反射场景，眼镜的亮斑给眼睛留出可见空间。近距离闪光主要照亮近处主体和实际覆盖范围内的背景。跳闪用场景中可用的墙面或顶面。
