# 光源形状、面积与多灯规划

用于在已选定的明显强闪观感上，扩展硬光、面光源、束光、跳闪和双灯方案。每个方案均运行“相对深度 → 语义材质 → 逐灯规划 → 图像编辑 → 实际审图 → 定向修订”的闭环；不靠给原图套不同色调区分方案。

## 先分清五件事

- **发光模式**：`emission=flash|continuous` 描述瞬时或持续发光，不决定阴影软硬。
- **有效发光面**：`shape` 描述主体真正看到的出光轮廓；柔光箱看扩散布，跳闪看被照亮的墙顶区域。
- **表观尺寸**：`effective_size` 描述该发光面从主体处看有多大，同时考虑宽高、距离和倾角。
- **灯位与指向**：`direction`、`elevation` 表示灯在哪；`aim` 表示它朝哪，不可混为一个“角度”。
- **新增光强**：`strength` 描述本次照片中需要的照明贡献，不是面积、瓦数或已测得的照度。

在曝光积分、空间分布、光谱与场景运动均相同的条件下，闪光和常亮的单张照片可能没有可辨差异。不要为区分两者擅加运动拖影、锐化、光晕或颜色偏移。
面积不直接决定总输出。扩大光源时，固定总能量和固定单位面积亮度是两种不同实验；不能只写“大灯更亮”。
灯头 `beam_zoom_mm` 只调覆盖范围，不能改变相机焦距、画面FOV、裁切、景深或透视。

## 沿用强闪基准的方法

用户已认可的强闪图是**照明观感对照**，不是下一张的内容底图。每个新版本仍编辑同一原图，不继承上一张的重绘细节。
默认保持主体有明确新增照明，并固定原有环境曝光和白平衡；更换形状不等于把强闪降成若有若无的填光。
比较光源形状时，可让主体主要受光区维持近似的目标亮度，分别调整各方案的虚拟输出，并记录进行了亮度匹配。
比较功率时必须固定光源形状、位置与其他设置，不再匹配亮度，否则会抵消强弱差异。
`high` 不要求所有表面都接近白。高光局部面积、纹理保留、前后衰减与合理投影比整图亮度更重要。
环境明亮时，硬闪可通过小高光、局部短硬影与主体受光区别体现，不必把后景改成黑夜。

## 统一方位与相对尺寸

左右以成片画面为准，不能随人物朝向或审图者视角变化。
`direction.azimuth_deg=0` 为相机近轴，−45° 为画面左前，+45° 为右前，±90° 为侧面，±135° 为侧后。
`elevation=0` 为受光主体附近水平高度，正数表示灯在上方；这些是虚拟创作设定，不是单图测量结果。
灯绕主体移动与灯头转向不同。跳闪必须同时写灯头所指表面及反射后到达主体的有效来光方向。

`effective_size` 推荐记录以下相对量：

```yaml
effective_size:
  apparent_extent: large       # small / medium / large；从目标受光区域看
  aspect_ratio: "2:3"          # 面光源宽:高；点源可写 null
  orientation: vertical       # vertical / horizontal / facing-subject / not-applicable
  distance_relation: near     # near / medium / far / unknown；相对场景尺度
  physical_dimensions: unknown
```

缺标尺和测距时不编造厘米、米或精确角尺寸。人物脸、全身和器材桌的尺度不同，同一光源对脸很大，对整桌可能只算中等。
表观大小还受发光面倾斜影响：圆盘可看成椭圆；斜着的矩形会变窄，不能始终画成正对镜头的完美形状。

## 光源参数结构

多灯统一放入 `light_sources[]`；单灯也用同一数组。额外保留原有环境光，不把现场顶灯或窗光误算成新加的灯。

```yaml
light_sources:
  - id: key
    shape: rectangle
    effective_size:
      apparent_extent: large
      aspect_ratio: "2:3"
      orientation: vertical
      distance_relation: near
      physical_dimensions: unknown
    direction: {frame_side: left-front, azimuth_deg: -45}
    elevation: 25
    aim: 主体脸至上身；兼顾相邻手部，避开无关远景
    emission: flash
    modifier: softbox
    strength: high
    color_intent: 中性补光，保留原环境色，不做全局变暖
  - id: fill
    shape: rectangle
    effective_size:
      apparent_extent: large
      aspect_ratio: "1:1"
      orientation: facing-subject
      distance_relation: medium
      physical_dimensions: unknown
    direction: {frame_side: right-front, azimuth_deg: 30}
    elevation: 10
    aim: 仅填补主灯背向面的暗部
    emission: flash
    modifier: softbox
    strength: low
    color_intent: 与主灯近似中性，不改变衣物固有色
```

`shape` 可用 `point-approximation / rectangle / octagon / annulus / strip / cylinder / disk / bounce-patch`。
真实小闪光灯仍有有限面积；`point-approximation` 是相对主体足够小的近似，不是宣称物理上零面积。
`modifier` 写有效整形方式，如 `bare / softbox / beauty-dish / grid / bounce`；需要叠加时明确描述“柔光箱加蜂巢”，不只写“柔光”。
束光是角分布而非发光面形状。聚光方案仍记录实际发光面，再补充窄束覆盖意图或已知的灯头设置。
面板按矩形有效出光面规划；是否有扩散层决定表观均匀性，不能凭空给每块反光表面贴LED点阵。灯管用细长圆柱 `cylinder` 并注明轴向、扩散层和径向出光；条形柔光箱用平面 `strip`，两者不是只换名称的同一灯。
`emission` 对应旧单灯字段 `emission_mode`，`strength` 对应 `flash_strength`；不得同时留下互相冲突的旧值。
`color_intent` 默认使用中性、保留环境暖光等定性目标；无测量或用户设定时不把推断色温写成实测值。

## 十二种可调方案

以下角度、尺寸与强度均是起点。用户指定场景、灯位或光质时随其调整；右侧版本可镜像灯位，不能翻转原照片。

| 方案 | 主灯或灯组设定 | 应能看见的区别 | 背景与主要条件 |
|---|---|---|---|
| `P1-axis-hard` 近轴强闪 | 小点源近似；0°，略高；`flash + bare + high` | 正面受光、小而集中的高光、局部短硬影 | 近处贡献大；身体影可藏在主体后方；不强行增加完整人物轮廓影 |
| `P2-left-hard` 左前硬光 | 小点源近似；−45°，约20°高；`flash + bare + high` | 受光面偏画面左侧，鼻/手/器材的投影偏向相反侧 | 只有实际墙地才能接影；可改+45°做右前版 |
| `A1-rectangle` 矩形大面光/面板 | 大矩形，竖向2:3；−45°，约25°高；柔光箱或带扩散层面板，`high` | 明暗过渡较宽，光滑表面可见窗形亮面 | 覆盖较宽但仍有距离衰减；不能变成全局无方向提亮 |
| `A2-octagon` 八角大面光 | 大八角；+35°，约25°高；`softbox + high` | 柔和立体感，眼部或漆面可能见近圆/八角高光 | 分辨率低或表面粗糙时形状可不清楚，不强制画八条边 |
| `A3-ring` 近轴环形光 | 镜头周围环状发光面`annulus`；0°，接近镜头高度；`high`，另记有无扩散层 | 近轴包围式填充；可见时形成环形/弧形眼神光 | 贴近背景时可能有围绕主体的影圈；不是所有场景都无阴影 |
| `A4-strip` 条形侧光/灯管 | 长窄竖向，约1:5；−70°，约15°高；平面条箱`strip`或扩散灯管`cylinder`，`high` | 细长反射、侧面塑形；两个方向的过渡宽度可能不同 | 条箱按单面、灯管按实际径向出光分别规划溢光；高光随曲率扭曲，不贴直白线 |
| `A5-beauty-dish` 高位圆碟 | 中等圆盘/灯碟；0至−20°，约35°高；`beauty-dish + high` | 比大柔光箱更利落的塑形，鼻下/下颌阴影可读 | 软硬仍受表观大小影响；灯碟不等于永远柔或永远硬 |
| `C1-spot` 小光源窄束 | 小圆盘或点源近似；−30°，约25°高；`grid + high`；瞄准主体局部 | 主体局部明显，周围溢光受控，边缘有合理过渡 | 光束截面由接收面倾角决定；清洁空气中不凭空出现可见光柱 |
| `B1-ceiling` 顶面跳闪 | 确认存在的浅色顶面作为大反射斑；有效来光偏上；`bounce + high` | 较广的顶部柔光，可能仍有眼窝和下颌阴影 | 记录灯→顶面→主体；无证据证明可用顶面时不选 |
| `B2-side-wall` 侧墙跳闪 | 确认存在的浅色侧墙作为大反射斑；有效来光−45至−70°；`bounce + high` | 柔和侧向渐变，近墙一侧受光更明确 | 记录灯→侧墙→主体；墙色影响新光，不能整张统一染色 |
| `D1-key-fill` 主灯加弱辅灯 | 左前大矩形主灯`high`；右前大面辅灯`low` | 保留主方向，同时抬起背向面；两灯反射位置分开 | 不让辅灯完全抹平主灯造型；分别计算照到背景与遮挡区的路径 |
| `D2-key-rim` 主灯加轮廓灯 | 近轴小主灯或左前大面主灯`high`；右后约+135°条形灯`medium` | 面部/主体主照明明确，朝向后灯的边缘出现局部轮廓 | 后灯不照亮所有边缘；头发、肩、器材边的遮挡不同，眩光需真实路径 |

`A1/A2/A4/A5/A3` 可在保持同一几何与曝光积分目标时切换 `flash` / `continuous`。这是一项发光模式变化，不另造相反的光质。
这里是虚拟照明的模式选择，不表示现实中的某一LED面板、灯管或闪光设备必然同时支持两种发光模式。
双灯默认先验证主灯，再检查辅灯或轮廓灯新增的贡献。需要单灯消融对照时分别从原图生成，不在已编辑图上叠加第二轮重绘。

## 表观面积、距离与衰减

软硬来自主体所见的有效角尺寸：相同物理发光面靠近通常更大、更柔；离远后相对更小，可变硬。形状改变也会改变不同方向的过渡。
大面光源近场需考虑整个发光面，不能把每个受光点机械套入单一 `1/r²`；很远且光源角尺寸足够小时才可近似点源。
点源近似下，新增直接照明随灯距平方衰减，还受灯束、入射朝向与遮挡影响；距离翻倍约降两档仅在这些条件不变时成立。
近主体主灯通常让前后层次的受光差异更强；远灯在匹配主体亮度后可让一定深度范围受光相对均匀。这里讨论的是新增光，不是删除背景环境光。
相机的相对深度不等于每盏灯的距离：侧灯、顶灯、后灯各自重新判断“近谁、远谁、被谁挡”。
跳闪包含灯到反射面及反射面到主体两段路径、反射损失和有效发光面，不能把两段简单相加后当作一个直射点源。
资料依据：[PBRT 面光源](https://www.pbr-book.org/4ed/Light_Sources/Area_Lights)、[PBRT 点源与聚光](https://www.pbr-book.org/4ed/Light_Sources/Point_Lights)、[broncolor 光质与距离](https://broncolor.swiss/news/hard-soft-and-diffused-light-what-is-the-difference)。

## 每盏灯都建立两条路径

**照明与阴影链**：灯的有效发光面 → 主体/前景 → 遮挡物 → 实际接收面。记录朝向、覆盖、受光强弱与投影软硬。
**镜面反射链**：灯的有效发光面 → 有法线/曲率的表面 → 相机。标注可见、有条件、不可见或未知，并说明判断依据。
镜面单列物理表面和虚像层：镜中主体的受光路径是“灯→真实主体→镜面→相机”；看见光源自身亮斑是“灯→镜面→相机”。镜中画面方向是表观设计目标，不直接当作真实灯位坐标；位置不能确定时记录未知。
大面光源只被遮住一部分时出现半影；不能对整片主体统一切换“见灯/不见灯”。多灯分别判断可见性，辅灯可照进主灯照不到的区域。

| 表面 | 光源形状如何可能出现 | 审图条件 |
|---|---|---|
| 眼睛 | 小点、矩形、八角、圆盘或环形的缩小反射 | 符合眼球朝向、眼皮遮挡和像素尺度；不强制每眼看到每盏灯 |
| 眼镜 | 局部灯面、亮条或点状反射 | 镜片曲率和头部姿态决定位置；需要保留双眼时先调整虚拟灯位，不消除所有合理反射 |
| 平面镜 / 抛光金属 | 反射方向允许时看见有效灯面或其变形 | 不给每块镜面复制同一高光；不凭空添加相机、支架、摄影师 |
| 弯曲金属 / 漆面 | 矩形、条形或圆形光源可被压缩、拉伸、截断 | 曲率、粗糙度和已有反射结构保持，不能用整片白色覆盖 |
| 透明杯 / 窗玻璃 | 局部前后表面反射与透射并存 | 保留杯沿、透过物体与窗后空间；不因反射光把玻璃变成墙 |
| 湿地 / 水面 | 符合视角的延展或碎裂亮斑 | 波纹/粗糙度改变形状；不是灯是什么形，路上就贴什么形 |
| 皮肤 / 绒布 / 哑光墙 | 多数表现为明暗过渡；皮肤/绒布可有材质高光 | 不把所有受光面当镜子，保留毛孔、绒毛、织纹和固有色 |

高光是几何、材质与发光面共同作用的结果；“长方形灯必然在每个物体上留下长方形”是错误约束。
反射原理依据：[PBRT 镜面反射与透射](https://www.pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission)。

## 各方案共用的执行与审图 Loop

1. **从原图锁定内容。** 记录画幅、FOV、人物/动物数量、姿态、器材位置、文字和原有模糊；强闪对照仅提供亮度与材质响应的目标。
2. **生成并审查深度辅助图。** 保持同视角、同对象边界，明确玻璃表面与窗后景、物理镜面与虚像；没有测距就只记录相对远近。原文件、画幅与场景未变时可复用已审图，并记录缓存依据。
3. **生成并审查语义材质图。** 分离皮肤/毛发、织物、漫反射地面、玻璃、镜面、金属、湿地、现场光源；误分先修，不把色板输入当照片风格。已审同场景材质图可缓存，每源光路不可直接复用。
4. **逐灯填写参数与路径。** 对每个 `light_sources[]` 项说明有效面、表观宽高、方向、指向、前中后景贡献、遮挡、投影与可能反射；双灯各写一遍。
5. **从同一原图实际编辑。** 将原图作为内容权威，已核对辅助图仅作照明依据；不要重拍人物、恢复原本失焦的纹理或搬动道具来配合灯。
6. **实际并排审图后定向修订。** 分别判断“照明方案能否读出 / 内容是否保留 / 形状与路径是否一致 / 未知是否被编造”。先处理最主要失败，修订仍从原图开始。

审查面光源时，除“更柔”外，至少检查一个可观察证据：半影宽度、面部过渡、高光面积/形状或受光覆盖。原图没有合适反射表面时，不为了证明灯形而添加物件。
审查窄束时检查溢光控制与受光覆盖，不能把整图暗角当聚光；审查跳闪时核对真实反射面；审查双灯时解释每处新增高光和每组投影由哪盏灯产生。
眼镜遮眼、整片桌布发白、金属变白块、动物眼睛发光、玻璃失透、远景全亮、额外硬影无接收面，都应记录并针对性修正。
原始模糊被改清晰、文字被重画、毛纹/细小器材被替换，需独立标记为保真限制，不能以灯光更明显抵消。
通常针对最主要问题修一次；保留首稿与审图记录。仍有问题时如实交付效果与残留限制，不把未运行方案写成已验证。
