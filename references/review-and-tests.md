# 审图与参数对照

## V3 人工评估实验优先约定

用户明确要求自行评估所有 Delta 候选时，助手只做技术验收，以下旧版审图意见不构成美学筛选门槛。各方法以一致的展示尺寸、强度说明和可查看参数并列交付；不打美学分、不推荐最佳、不删除不喜欢的结果，也不为了助手的审美判断反复生成完整参考。

V3 技术记录至少包含原件/参考哈希、EXIF 显示尺寸、色彩转换、工作尺寸、参考配准与回退、实际过滤参数、正负变化及显示裁切比例、输出路径和透明层重建误差。配准只能变换参考，原图不做几何变形。零 Delta/零强度恒等、有限值、原件未覆盖和原尺寸检查使用确定性测试；通过仅说明处理行为，不说明自然度。

保留未配准与配准后原始差值对照，以及处理后的工作尺度浮点场。求差生成的 Delta 可能携带人脸、文字或纹理漂移，不能把有符号负变化或可见重影自动当作应删除的审美失败；记录它们与处理条件，交给用户比较。明显技术错误则标注失败、保留参数和原因，不伪造结果或静默改用别法。

用户选择 V3 时，完整结果求差是已选策略；“不得把重绘照片残差冒充直接生成蒙版”仅针对 V2 的来源表述。详见 [Delta 迁移实验](delta-transfer.md)。

## 每张成图验收

| 项目 | 看什么 | 未通过的例子 |
|---|---|---|
| 内容/人物 | 人脸比例、眼镜、服装、手部、物件数量与位置、文字 | 换脸、少了一只杯子、增加相机 |
| FOV与几何 | 原画幅、画面边缘、跨区域锚点、直线与透视 | 放大裁切、窗框位移、桌沿弯曲 |
| 深度响应 | 近中远层的新增光、遮挡、离机距离 | 天空和前景一起提亮 |
| 阴影链 | 逐源灯位、真实接收面、半影、原环境填充、可见性 | 透明窗后出现实墙人影、双灯投影来源无法解释 |
| 材质反射 | 眼镜可读、透明度、金属和湿地的局部高光 | 每块玻璃同一个白点，路面全白 |
| 光质/光源形状 | 表观尺寸、软硬过渡、面/条/环形高光的成立条件 | 用磨皮代替柔光、每个表面贴同款长方形、偷偷加灯 |
| 镜面分层 | 物理镜面、虚像主体、灯的镜中反射各自路径 | 镜中人物当成贴在镜面上的实体、虚像当接影墙 |
| 发光模式 | 每源flash/continuous与几何、强度分别设置 | 为区分常亮与闪光擅加模糊、光晕或全局色差 |
| 环境保留 | 原光色、远景、既有灯和反射 | 自动追色把闪光抹掉，远景换成白天 |
| 照明完成 | 新增光有方向、距离、发光面与材质差异 | 只有全局曝光抬升、换了灯名却无可观察差异 |

逐项记 `达到 / 部分达到 / 未达到 / 无法确认` 及一条可观察理由。不要强行给百分概率或总分。真实量测未做就不要编造锚点误差数字；像素尺寸一致也不能证明FOV没变。

用户要明显闪光或比较预设时，先把原图和结果放到正常视频缩览大小检查，再看原像素局部。直闪至少要能在实际存在的受光面、集中反光与短遮挡中指出同一灯的作用；侧柔看可辨的来光侧与背光侧、较宽过渡；双灯看保持主灯后新增的发肩贡献。整体更亮、皮肤更粉，或文件名不同而缩览观感近似，不能据此判光效达到。无需为没有反射条件的表面强加白点，也不靠涂黑原环境制造硬影。

在约定保留环境曝光的 V1/V2 制作中，窄覆盖与远景保护尤其要检查原有环境光：没有照到某处，只代表没有新增光，不意味着可以降低该区域原有亮度。对照原图中未被遮挡的天空、远建筑或墙面；有分析工具时可记录相同区域的线性RGB平均亮度变化，作为漂移的辅助证据，不当作实测照度。区域需要避开重影、边缘位移或新增高光，数值接近也不能证明纹理无损。V3 有符号实验则保留完整参考的负变化、记录背景是否变化，交给用户比较；不自动按加光模式把它截掉。

需要助手审图的普通制作中，独立审图者只拿用户请求、技能、原图、辅助图、实际参数和成图，先看再评价，不给它预设好坏结论。没有独立能力时标记“同模型自审”。V3 用户自行美学评估时，不另外委派美学打分或选片任务；技术检查与数据完整性审查仍可独立执行。

## V2 光照层与原尺寸合成

除上表外，检查以下可观察结果：

| 项目 | 核查方式 |
| --- | --- |
| 原件保留 | 比较输入文件哈希，确认没有覆盖用户原件 |
| 原始网格 | 输出尺寸等于 EXIF 转正后的显示尺寸；区分原存储宽高与显示宽高，核对边缘和锚点 |
| 控制图角色 | 模型只输出增益或加性光数据，不能混用 `128` 灰底与 `0` 黑底；无五官、眼镜线条、发丝、衣料格纹、文字或背景。灰度照片同样不合格，不得用重绘照片残差冒充直接生成蒙版 |
| 零变化恒等 | 零强度，或中性 `128` 增益且加性光为 `0` 时，应与相同色管/方向处理后的原图解码像素一致；仅 EV 为零、有加性光的位置不属于不变区。这是合成行为验证，不能据此推断灯光正确 |
| 覆盖保护 | 覆盖蒙版为零的区域维持相同像素；另看天空与远景是否被错误纳入覆盖 |
| 原纹理来源 | 对齐放大查看眼睛、衣料、小字和颗粒，确认没有新几何与生成纹理；提亮后显出原噪声不算生成新细节。增益与加性光会改变局部对比，不能称微纹理像素值不变 |
| 边缘处理 | 检查发丝、眼镜、肩缘与明暗交界的漏光、暗边、连续描线和不合理模糊；不能把硬影全抹软 |
| 颜色与亮部 | 检查皮肤色偏、三通道差异、亮部压缩和白块；注明输出 8 位 sRGB，不宣称 RAW 或广色域无损 |
| 加性高光 | 检查鼻尖/颧区等实际反射位置，不能变成漂移白斑或遮眼镜片；亮部须与漫反射灯位一致，不能以近白块抹掉全部纹理 |
| 透明层 | 在同一 sRGB 底图上按正常模式合成，核对是否重建最终输出；以脚本实际验证误差为准，并检查目标软件的混合空间 |
| 逐灯开关 | 分别检查增益 `field-strength=0` 与加性 `additive-strength=0`；若同一灯拆成两类场，要关闭两份或关闭其整灯 NPZ。其它灯应保留；权重与各类输入顺序、数量须一致，先合计全部线性新增贡献，再做一次高光压缩 |
| 浮点场复用 | 同一原件 NPZ 同时复用 `ev` 和可选 `additive_linear`，不能丢失黑像素上的加性光；不重复引导/平滑或旧覆盖。核对原件哈希、尺寸与模式，合并场不冒充逐灯场 |

光照场的分辨率、编码与生成式估计误差会影响影子和反光的位置。原照片没有重绘，不等于新增光的边界正确；需要分别给出“合成保留原网格”“灯光可辨与方案区分”“照明效果自然”的结论。加性光可以照亮原黑像素，但不能恢复原图全黑或过曝处的信息。未实际查看成图不能宣称改善已完成，也不能代替用户对效果的确认。

对透明层重建、恒等与保护区测试使用确定性样例即可；这些合成测试不代替实拍效果验收。可运行 `python scripts/test_relight_layers.py` 检查脚本行为，并在报告中写实际结果，不把测试数量当作效果质量分数。

## 用户要求测试时

测试图与成品分开。优先用用户提供或从公开来源取得的真实手机摄影，核对来源页面、拍摄设备证据和可用许可，保留原文件与哈希；未提供私人图时可自行查找可下载的公开实拍，不以缺用户照片为由默认生成输入。生成模型制作的原图会带来模型偏差，只能作为另行标记的合成流程测试，不能代替真实摄影验证。用户要求实拍测试时，所有正式测试输入必须来自实拍，不将原图预先重生图、美化、去噪或替换。推荐覆盖：

1. 室内人物＋眼镜＋玻璃杯＋金属＋近墙＋窗外远景：先做近轴硬闪，再做侧向柔光。
2. 室外湿地面＋玻璃门＋近处植物＋远街：做低/高功率对照，检查湿地反射与远景保护。

这是一组覆盖建议，不强制普通用户每次生成四张或跑完整光源目录。用户指定数量和场景优先。每个场景先生成并核对两张辅助图；原文件、画幅和场景边界未变时可以缓存并记录复用，每源照明与反射路径仍重算。V2 各方案分别生成光照场并从原始文件合成；认可的强闪只作目标观感。记录具体输入顺序和完整提示词。

区分比较目的：

- **强度对照**：同原图、灯位、modifier、灯头覆盖、环境策略，仅改变目标视觉强度/同一虚拟设备功率。其它生成设置在接口允许范围内保持一致，无法锁随机种子就如实记录；不能称严格可重复实验。
- **光质对照**：固定原图和灯位，改变发光面表观大小；若同时改功率补偿，单独写明。硬直闪与左侧柔光一起变化只能称预设效果展示，不能归因于单一软硬变量。
- **灯位对照**：固定光质、目标强度与原图，改灯位并更新阴影与反射路径；不要复用另一个灯位的路径图。
- **形状/面积对照**：按 [光源形状与多灯规划](source-shapes.md) 比较矩形、八角、条形箱/灯管、环形等。记录是否匹配主体亮度；若同时改变方向、距离或大小，只称预设展示，不归因为形状单一变量。
- **发光模式对照**：几何、光谱与曝光积分目标相同的闪/常亮单帧可无明显差异，这不自动判失败；不能伪造时间特征来让差别可见。
- **双灯对照**：主灯参数固定，分别检查主灯与新增辅灯/轮廓灯的贡献。V2 若使用单张合并控制图，不能称已分离验证每盏灯；若分别生成两源图，应在线性空间合计新增光贡献，各对照均从原图合成。V1 不把在成图续改造成的重绘当第二盏灯的物理效果。
- **流程收益对照**：若要声称“比原技能更好”，需在同源图、相同光照目标下另跑原流程并独立比较。没有这组证据只能报告新流程可执行和本次视觉结果。
- **Delta 传递对照（V3）**：同一完整参考、原图、工作尺度和强度下比较方法；未配准/配准、辅助图引导、软覆盖与光流等改变均单列说明。所有候选保留，由用户评估美感；不把结果文件数量或数学测试通过率当作更好看的证据。

保留原始输入文件、`depth.png / materials.png / 各版本首稿 / prompts.json / review.md`。V2 还保留实际生成的光照场、覆盖蒙版（若有）、透明效果层、合成报告及需要重算的浮点增量。输出中的漏光、色偏、细节漂移、阴影不明显或功率不单调都应记入结果，不丢掉首稿挑最好的一张冒充稳定性。通常修一次最主要失败；全部版本对照报告应同时保留修前修后。

## 停止条件

V3 不以助手审美为停止条件。完成约定方法的技术检查与并列输出即可交付用户选片；配准失败时记录回退，算法缺少所需辅助图或数值失败时保留失败记录。未选择的方法记“待人工选择”，不擅自追加一轮生图或悄悄将全部候选换成自己偏好的版本。

一般制作中，原图或必需工具缺失时交付缺项与待执行简报；有同源参考的 V3 可继续本地实验，不因缺新生图工具停止。辅助图缺失时标记对应方法不可运行，纯算法分支可按约定保留。V1/V2 常规制作若光照场错位、含照片纹理或成图几何/身份失败，针对主要问题通常修一次，仍失败就交付现状与限制，不无限抽卡、不自动换路线。
