# 审图与参数对照

## 每张成图验收

| 项目 | 看什么 | 未通过的例子 |
|---|---|---|
| 内容/人物 | 人脸比例、眼镜、服装、手部、物件数量与位置、文字 | 换脸、少了一只杯子、增加相机 |
| FOV与几何 | 原画幅、画面边缘、跨区域锚点、直线与透视 | 放大裁切、窗框位移、桌沿弯曲 |
| 深度响应 | 近中远层的新增光、遮挡、离机距离 | 天空和前景一起提亮 |
| 阴影链 | 逐源灯位、真实接收面、半影、原环境填充、可见性 | 透明窗后出现实墙人影、双灯投影来源无法解释 |
| 材质反射 | 眼镜可读、透明度、金属和湿地的局部高光 | 每块玻璃同一个白点，路面全白 |
| 光质/光源形状 | 表观尺寸、软硬过渡、面/条/环形高光的成立条件 | 用磨皮代替柔光、每个表面贴同款长方形、偷偷加灯 |
| 镜面分层 | 物理镜面、虚像主体、灯的镜中反射各自路径 | 镜中人物当成贴在镜面上的实体、虚像当接影墙 |
| 发光模式 | 每源flash/continuous与几何、强度分别设置 | 为区分常亮与闪光擅加模糊、光晕或全局色差 |
| 环境保留 | 原光色、远景、既有灯和反射 | 自动追色把闪光抹掉，远景换成白天 |
| 照明完成 | 新增光有方向、距离、发光面与材质差异 | 只有全局曝光抬升、换了灯名却无可观察差异 |

逐项记 `达到 / 部分达到 / 未达到 / 无法确认` 及一条可观察理由。不要强行给百分概率或总分。真实量测未做就不要编造锚点误差数字；像素尺寸一致也不能证明FOV没变。

窄覆盖与远景保护尤其要检查原有环境光：没有照到某处，只代表没有新增光，不意味着可以降低该区域原有亮度。对照原图中未被遮挡的天空、远建筑或墙面；有分析工具时可记录相同区域的线性RGB平均亮度变化，作为漂移的辅助证据，不当作实测照度。区域需要避开重影、边缘位移或新增高光，数值接近也不能证明纹理无损。背景明显变暗时记部分/未达到，并针对恢复原环境光修一次；残留漂移仍应记录。

独立审图者只拿用户请求、技能、原图、辅助图、实际参数和成图，先看再评价，不给它预设好坏结论。没有独立能力时标记“同模型自审”。主代理也要查看输出，不能仅转述审稿评分。

## 用户要求测试时

测试图与成品分开。优先用用户提供或从公开来源取得的真实手机摄影，核对来源页面、拍摄设备证据和可用许可，保留原文件与哈希；未提供私人图时可自行查找可下载的公开实拍，不以缺用户照片为由默认生成输入。生成模型制作的原图会带来模型偏差，只能作为另行标记的合成流程测试，不能代替真实摄影验证。用户要求实拍测试时，所有正式测试输入必须来自实拍，不将原图预先重生图、美化、去噪或替换。推荐覆盖：

1. 室内人物＋眼镜＋玻璃杯＋金属＋近墙＋窗外远景：先做近轴硬闪，再做侧向柔光。
2. 室外湿地面＋玻璃门＋近处植物＋远街：做低/高功率对照，检查湿地反射与远景保护。

这是一组覆盖建议，不强制普通用户每次生成四张或跑完整光源目录。用户指定数量和场景优先。每个场景先生成并核对两张辅助图；原文件、画幅和场景边界未变时可以缓存并记录复用，每源照明与反射路径仍重算。所有版本均从原始JPG/原始文件生成，认可的强闪只作目标观感。记录具体输入顺序和完整提示词。

区分比较目的：

- **强度对照**：同原图、灯位、modifier、灯头覆盖、环境策略，仅改变目标视觉强度/同一虚拟设备功率。其它生成设置在接口允许范围内保持一致，无法锁随机种子就如实记录；不能称严格可重复实验。
- **光质对照**：固定原图和灯位，改变发光面表观大小；若同时改功率补偿，单独写明。硬直闪与左侧柔光一起变化只能称预设效果展示，不能归因于单一软硬变量。
- **灯位对照**：固定光质、目标强度与原图，改灯位并更新阴影与反射路径；不要复用另一个灯位的路径图。
- **形状/面积对照**：按 [光源形状与多灯规划](source-shapes.md) 比较矩形、八角、条形箱/灯管、环形等。记录是否匹配主体亮度；若同时改变方向、距离或大小，只称预设展示，不归因为形状单一变量。
- **发光模式对照**：几何、光谱与曝光积分目标相同的闪/常亮单帧可无明显差异，这不自动判失败；不能伪造时间特征来让差别可见。
- **双灯对照**：主灯参数固定，分别检查主灯与新增辅灯/轮廓灯的贡献。单灯参考也从原图生成；在成图继续叠加造成的重绘不当作第二盏灯的物理效果。
- **流程收益对照**：若要声称“比原技能更好”，需在同源图、相同光照目标下另跑原流程并独立比较。没有这组证据只能报告新流程可执行和本次视觉结果。

保留 `source.png / depth.png / materials.png / 各版本首稿 / prompts.json / review.md`。输出中的细节漂移、阴影不明显或功率不单调都应记入结果，不丢掉首稿挑最好的一张冒充稳定性。通常修一次最主要失败；全部版本对照报告应同时保留修前修后。

## 停止条件

原图或必需工具缺失：交付缺项与待执行简报。辅助图失败：记录降级，不宣称完成全流程。成图几何/身份硬失败且一次修订仍未解决：交付失败项与当前图片，不能宣称通过。仅有轻微高光形状未知：允许交付并标明，避免无止境重试。
